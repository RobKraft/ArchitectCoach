# Local setup checklist

- [ ] Clone the repo.
- [ ] Install Node.js and run `npm install`, then the generator's dev-server command (e.g. `npm run dev` / `npm start`, check its docs) to preview locally.
- [ ] Confirm the site matches what's currently deployed before making changes.
- [ ] Read `docs/coding-standards.md` for this project's specific conventions before your first commit.
